Formats

Create and scan codes from the same app.

Use barcode generation when you need a linear or PDF417 code, and QR templates when the content is a link, Wi-Fi network, contact, event, social profile or location.

EAN-13 and UPC-A

Numeric product-style barcode generation with format-specific validation.

Code 128

Flexible text barcode generation for labels, internal workflows and references.

PDF417

2D barcode generation for denser text payloads where the format is required.

Workflow

From value to exported file.

  1. Choose Barcode inside inQRedible.
  2. Select EAN-13, UPC-A, Code 128 or PDF417.
  3. Enter the value and let the app validate the format where required.
  4. Export or share the generated image from your iPhone.
