Guest Wi-Fi QR

Create a Wi-Fi QR code on iPhone.

Use inQRedible to turn Wi-Fi details into a scannable QR code for guests, customers, teammates or event attendees. The template supports open networks, WEP, WPA/WPA2 and hidden networks.

Download freeSee templates

Steps

Share a network without spelling the password.

A Wi-Fi QR code stores the network name, security mode and password in a standard format. Visitors scan it with their phone instead of typing credentials manually.

  1. Select the Wi-Fi template in inQRedible.
  2. Enter SSID, password, WPA/WPA2, WEP or open security, and hidden-network status.
  3. Customize colors, logo and shape if the code will be printed for guests.
  4. Export the PNG and place it only where intended; the QR contains the network details entered, so anyone who can scan it may be able to use them.
