QR y barras

Generador de códigos de barras para iPhone.

inQRedible crea QR y códigos de barras comunes desde una app nativa iOS. Genera EAN-13, UPC-A, Code 128 y PDF417, escanea formatos compatibles y conserva historial creado y escaneado en tu dispositivo.

Formatos

Crea y escanea códigos desde la misma app.

Usa generación de barras cuando necesites un código lineal o PDF417, y plantillas QR cuando el contenido sea enlace, Wi-Fi, contacto, evento, red social o ubicación.

EAN-13 y UPC-A

Generación de códigos numéricos con validación específica de formato.

Code 128

Generación flexible para etiquetas, flujos internos y referencias.

PDF417

Código 2D para cargas de texto más densas cuando ese formato es necesario.

Flujo

Del valor al archivo exportado.

  1. Elige Código de barras dentro de inQRedible.
  2. Selecciona EAN-13, UPC-A, Code 128 o PDF417.
  3. Introduce el valor y deja que la app valide el formato cuando aplique.
  4. Exporta o comparte la imagen y compruébala con el sistema receptor; validar el formato no garantiza compatibilidad con todos los lectores o flujos.
